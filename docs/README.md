# File Compass user guide

**F1** or **Help → Program help** opens native offline help with categories, accent-insensitive search, related-topic links and Back/Forward history. F1 opens the matching topic in supported dialogs. Ctrl+F focuses help search; Alt+Left/Right navigates history and Escape closes help. Core content is available in Czech and English; other interface languages use English help. Detailed in-app guides are also available in Czech; original third-party notices remain in their original language. Repository reference documents are predominantly English.

**Help → About File Compass** shows the application logo, the Rathousky.pro developer logo, version, build ID, actual build date and a clickable GitHub link. Copy information copies version/build/UTC timestamp and Windows version without profile paths.

File Compass is a Windows file manager by Rathousky.pro. Start **File Compass.exe** with all supporting installation directories. Settings are in `config`, working/account data in `data`, translations in `languages`, .NET libraries in `libraries`, native tools in `plugins`, artwork in `icons`, renderer assets in `preview`, and this guide in `help`. WebView2 working data is stored in system TEMP.

## Getting started

- Choose side-by-side, stacked or single-panel layout from the toolbar or View menu.
- F2 opens a new unnamed text document; Shift+F6 still renames. F3 opens the viewer, F4 the editor, F5 Copy, F6 Move, F7 New folder and F8 Delete. Enter runs the default action in copy/move/delete confirmation dialogs; Escape cancels.
- Preview, Ctrl+Q and Ctrl+Shift+Q control the same preview: in the opposite panel, or below the list in single-panel mode. Collapse the lower preview using its header.
- The toolbar groups display/navigation, search/bookmarks, file actions, tools, archives, and connections separately. One icon-only button cycles side-by-side → stacked → single-panel layout and changes its drawing to match the current mode. Its tooltip describes the cycle. Hidden files use an icon-only toggle, followed immediately by Invert selection and Undo. Preview and Thumbnails are adjacent. Tools opens analyzer, SMART, image conversion and audio conversion commands; Synchronize opens the folder synchronization setup without applying changes. Direction arrows open one panel's folder in the other and are hidden in single-panel mode. Groups wrap together in narrow windows.
- Returning to a parent selects the folder just left. Automatic refresh keeps unchanged rows, selection and scroll position.

Escape closes secondary windows and tools through their normal cancel/close behavior. Existing unsaved-change prompts and running-operation closing guards remain active. Busy background-capable tools cancel safely and close once their operation becomes idle. An open selector or menu consumes Escape before its host window; Escape does not exit the main file manager.

Open tabs occupy the breadcrumb/path row itself; there is no additional tab row. Tabs use bounded widths based on their path lengths; short drive roots stay compact. When paths do not fit, both active and inactive tabs reuse the copy dialog middle-compaction rule, keeping the drive/root and path ending visible with the full path in a tooltip. The active tab retains breadcrumb navigation when its full path fits. Ctrl+L or the pencil edits the active path. The + button/Ctrl+T opens another tab and Ctrl+W closes one; each panel has its own open-tab set. Saved bookmarks are a separate list under the star button. Adding a bookmark saves a location without opening a tab; choosing one from the panel star menu opens a new tab in that panel. The list supports groups and bookmark management. Closing a tab does not remove a saved bookmark. Open tabs and bookmarks are saved separately, and startup restores only the open-tab set. Locked home tabs remain a separate optional tab behavior. Missing folders, disconnected drives and remote tabs retain their saved targets and show an explicit unavailable state with Retry/connect; remote login occurs only on explicit opening.

Quick preview and the bottom detail pane can browse multiple marked files through a horizontal selection strip. Images receive lazy thumbnails; documents retain their file icons and use the existing document/text preview. Click a strip item or focus the strip and press Left/Right to change the enlarged preview without changing panel marks or cursor. Only the active item loads its full preview and detailed metadata. Changing file marks updates the strip; single-file selection hides it. The bottom pane reserves room for the enlarged image when the strip is visible. Details use a compact heading and readable alternating key/value rows. The internal editor uses the shared clean frame with encoding/line-ending controls and Save/Close footer; F4 still opens only the panel cursor file, and existing document tabs/save safeguards remain available.

**F2 New file** in the bottom action bar, New file in the File menu, or Ctrl+N, opens an unnamed blank document in the internal editor. Choose its name and extension on the first Save. New documents default to UTF-8 without BOM and LF line endings, suitable for Linux/Unix text files. The format bar offers syntax selection before a name is chosen, including Shell/Bash and RouterOS, encoding choices, and LF / CRLF or preservation of original endings. Existing files retain their encoding/BOM and original line endings, including mixed endings, unless explicitly converted. Format-only changes are unsaved changes too. Characters unsupported by the selected encoding stop saving rather than becoming replacement characters. This creates plain text files, not binary documents.

New documents remember the panel folder/connection where they were opened. Local folders and mapped/network drives use a compact application dialog asking only for the filename, including any extension. The destination stays fixed to the folder captured when New file was opened, even if the panel subsequently navigates elsewhere. Existing names require overwrite confirmation. FTP/SFTP/SCP destinations prompt for a filename in that captured remote folder and stage uploads through an independent connection; existing remote targets require overwrite confirmation, and changed target metadata prevents silent replacement. Failed/cancelled saves retain the document text. SSH credentials and host-key checks come from the selected connection profile. Archive and virtual overview locations require opening a writable folder first. Shell/RouterOS highlighting is lexical assistance, not a script execution or compatibility check.

Video preview uses six FFmpeg still frames at 10, 25, 40, 55, 70 and 85 percent of the video duration. Click a timestamped thumbnail or focus its strip and press Left/Right to enlarge that frame. The source-file strip remains separate for mixed selections. Frames load progressively in the background, and changing sources cancels old decoding. Play video opens the existing player. Local frame caches are bounded to 128 sets, 256 MiB and 30 days and are invalidated when the source or FFmpeg changes. Network shares require an explicit read action; FTP/SFTP previews require an explicit full download (maximum 512 MiB) into temporary storage. No remote video is downloaded merely by moving the cursor.

## Appearance and language

Copy and archive progress use the same unified layout: a large total percentage and blue overall bar, followed by a thinner blue current-file bar. Archive preparation shows the preparation summary and current filename without progress bars or placeholder percentages; the indicators appear when compression starts. Expand Transfer details for full paths, measured copy speed, speed history and compression statistics. When an archive tool cannot report individual file progress, the file indicator remains indeterminate. Copy, delete, archive creation and extraction dialogs share the same header, clean form and action footer. Copy/move and archive creation use sidebar categories with a stable window height. Copy offers General, File selection, Properties, Verification and rights, and Presets; archive creation offers General, Split archive, File handling, Security, and Tools. Switching categories preserves entered values. F8 opens the copy file mask category; F7 creates a destination folder and F2 queues the operation.

Existing-file conflicts compare the destination and incoming file side by side, including size, timestamp and paths. Matching size and time do not imply identical contents. Overwrite and Skip affect one conflict unless the explicit task-wide checkbox is selected; Rename and Append are immediately available on the Basic sidebar page; task-wide rules have a separate sidebar page. Switching pages preserves the dialog height and choices. Deletion confirmation separates the selected items from removal methods, explicitly labels permanent deletion and keeps the appropriate Recycle Bin default when available. Background copy uses blue direction arrows and a thicker blue progress line, with file count, speed and remaining time below it. Pause/Resume and Details remain directly available in both theme styles.

The network copy/move confirmation also uses the shared operation header/footer and Basic/Transfer details sidebar pages. Source, destination and existing-file behavior have separate outlined sections. Skip, Overwrite and Resume remain immediately available; Enter retains the Skip default. Move confirmation displays the source-deletion notice in its header. Protocol-specific resume/restart guidance is retained.

Network copy uses the same overall/file progress hierarchy as local copy in both theme styles. Transfer details contain full source/target paths, measured MiB/s and speed history. The file queue, item cancellation/reordering and KiB/s speed limit remain available below the progress area. Pause/Resume, transfer cancellation, history and background actions remain in the footer. Multiple simultaneous transfers can be selected above the queue; switching transfers restores its speed-limit value. Expanded details scroll when needed to keep footer actions reachable.

All seven configuration sections share the clean settings frame: a grey section sidebar, white working area, outlined option groups and a persistent Cancel/Save footer. This includes Appearance, Icons, Archives, Viewers, View on startup, Network connections, and Files and operations. Related network-profile editors, cloud account creation/rename/authorization questions, and archive-plugin dialogs use matching headers and action footers. Theme and icon previews still revert on Cancel; network/cloud management retains its immediate-save behavior. Pages scroll on smaller displays so footer actions remain reachable. The clean appearance is the only interface style; light/dark modes remain available.

Disk Space Analyzer and Disk health / SMART use the shared clean tool frame with grey headers/action footers, white work areas and thin section outlines. Analyzer retains its result tabs, filters, charts, comparisons and exports; the folder pane has additional width for readable names. SMART combines title and disk selection in one header and keeps drive information separate from diagnostic tables. Compact split SMART tables use dense 11-DIP text while preserving all rows and full export data. Semantic health/temperature and chart-category colors are retained. Light/dark modes are supported.

File search uses compact multi-column General and Advanced forms instead of page-level scrolling; results keep their own scrolling for long lists. Metadata and saved-profile pages remain available. Tag search refers to custom labels assigned in File Compass, not names or automatic content recognition; an empty query shows all tagged files, and the compact query dialog explains this. Image/audio converters share the clean tool header, outlined settings, white file queue and grey action footer. Compact mode preserves queue space at smaller heights and retains basic, advanced, speed and duration options.

Media concurrency means complete files converted simultaneously (1, 2, 3, 4, 6 or 8), independent of CPU count. Choosing eight files on a four-thread CPU is allowed, but can increase memory/scheduling costs without improving speed. The image engine uses Magick.NET Q8 OpenMP 15.0.0 with matching native/runtime libraries. Internal OpenMP and audio encoder/filter thread requests adapt to detected logical CPU count and the number of concurrent files; image caps reflect the tested JPEG/WebP workload, while codec delegates can have their own threading. These budgets are not OS-wide CPU quotas. Source files remain untouched and outputs retain the existing verification and cancellation behavior. Settings → Updates lists the OpenMP engine version; its managed/native/runtime set updates together with File Compass, separately from FFmpeg updates.

The media queue has a separate right-aligned percentage column, preserving percentages when status messages are long. The footer estimates remaining time after a short measurement warmup, using original audio durations (image pixel/frame counts for images), observed per-file progress and concurrent worker slots. Overall progress uses these work weights rather than treating a short and a long recording equally. Failed items do not count as speed samples, and the last long file retains its own remaining-time estimate. A finishing message replaces the countdown at the final stage; estimates remain approximate. ETA is also included in the background activity description.

Tabs throughout the application, including nested converter settings, use visible individual outlines and spacing. The active header has a subtle blue tint, a complete rounded outline and semibold caption without an underline; only the header is emphasized, while page content retains neutral colors and stretches to the available area. Hover, keyboard focus and disabled states are differentiated. Folder-panel tabs also have stronger outlines. The complete rounded outline is inset inside each header so the active tab is not clipped on its right edge. The common treatment applies in light/dark modes.

Settings → Appearance offers light/dark/system modes, Solid/Mica/Mica Alt backgrounds and font-size arrows. The single clean interface uses white and pale-grey surfaces, thin blue outlines and blue transfer indicators throughout application windows and dialogs. Toolbar arrangement, function keys and native file icons are retained. Appearance and icon choices are previewed live; Cancel restores saved settings and Save persists them. English is the default for a fresh installation; Czech, German, Spanish, Dutch, Polish, French and Portuguese are also available. Language changes apply immediately after saving, without restarting. Open panels, selections and transfers stay in place; Cancel keeps the current language. Mica requires supported Windows 11; unavailable effects fall back to a solid background.

## Disk analyzer

Open Commands → Disk tools → Disk analyzer, or the panel context menu. The active panel's **current folder and all subfolders** are preselected, not automatically the drive root. Opening the analyzer does not start a scan: configure the scope and filters, then choose **Start analysis**.

The analyzer opens on Scope and filters and waits for **Start analysis**. Starting a valid scan switches to Results; Progress and diagnostics has a separate top tab, so settings and diagnostics do not reduce the graph and file-list area. Grouping, metric and percentage base sit above the file list; the chart type selector sits directly above the graph. The initial width is measured from translated tab/button captions and the current text styles, and adjusts when the language changes. Tabs stay in one row; narrow screens use horizontal scrolling rather than wrapping or cutting off controls. Drag the vertical divider to resize the file list and chart; drag the horizontal divider to resize the chart and legend. Switching tabs preserves the current scan and display choices. Editing parameters preserves previous results and marks them as belonging to the previous analysis until you choose Analyze again. Enter in a single-line parameter field also starts analysis; multiline scope fields retain normal text entry.

The tree shows folder byte totals and file counts. Selecting a folder changes its folder chart. Donut/pie and bar charts group by folders, extensions, categories, modification age or size ranges, using bytes or file counts. Category/extension/age/size statistics apply to the original analysis root displayed above the chart.

Click a segment to list its files; Other includes every grouped category. The full file list uses a temporary disk index with 1,000-row pages, separate from the top 100 largest files. Closing the window or starting a new scan removes the index.

Combine category, minimum MiB, days since modification, name masks and excluded folders. Separate masks/exclusions with semicolons; exclusions accept names or relative/absolute paths. Start analysis / Analyze again applies the current parameters in a fresh scan. Invalid parameters leave prior results available. Categories use file extensions, not content inspection: images, video, audio, documents, archives, source code, applications and other.

Totals, charts, first-level folders, largest files and skipped items update about every half second while scanning. Detailed trees appear at completion; an open chart file list refreshes at most every two seconds. Stop retains a marked incomplete result.

Completed results export to CSV (all filtered files), standalone HTML with charts/tables, or PNG of the current chart at double resolution. PDF export is not implemented. Save analysis writes an FCA file with folder aggregates. Compare with saved analysis shows growth/shrinkage and added/removed folders; both scans must be complete with the same root and filters. Do not sum comparison rows: folder totals include descendants. Find duplicates opens the existing tool for the selected folder or analysis root.

Sizes are logical lengths, not allocated space. Hard links can count more than once. Links and reparse/mount points are not followed. Inaccessible items are skipped; at most 500 detailed skip records are kept, with a complete total count. Local folders and available mounted/network paths are supported; archive interiors and direct remote protocols require a local/mounted folder.

## Disk health / SMART

Commands → Disk tools → Disk health / SMART lists physical disks. Available data includes identification, volumes, temperature, SMART status, power-on hours/cycles, NVMe wear and read/write totals. SATA provides normalized/raw attributes; NVMe provides its health log. Unknown vendor attributes keep their original names. Missing values are identified, not estimated.

Select a disk from the top tile row: each tile shows health, temperature, drive letters and model. A compact icon and labeled badge distinguish HDD, SSD and NVMe using diagnostic rotation/protocol data; the selected disk also shows its type beside the model. Restrained type accents are independent of health colors. USB or SCSI identify the device interface when its medium is ambiguous; absent metadata is marked Unknown rather than guessed from the model name. Many disks scroll horizontally; arrow keys navigate the tiles. Refresh preserves the selected device. Clipboard copying briefly retries if another application holds the clipboard, then offers a clear retry/TXT fallback message. Refresh manually or every one/five minutes, copy details, or use Save report to export PNG, PDF, TXT or JSON. The adaptive window places drive information beside the SMART table and splits attributes into two tables when needed. Health and temperature use prominent, contrasting tiles. PNG captures the complete result rather than the visible viewport; long PDF reports use multiple landscape pages. NVMe remaining percentage is 100 minus reported percentage used, not a failure prediction. Some SATA disks do not provide reliable lifetime or byte-count summaries.

smartmontools 7.5 runs as a separate `smartctl.exe`; GPLv2 license and corresponding source archive are in `plugins/smart`. Only diagnostics are read: no drive configuration changes or surface tests. If needed, elevation opens a separate SMART-only process; the main manager keeps its original privileges. Support depends on drive/controller/USB bridge. SMART does not replace backups.

Background tools use the same bottom activity dock as transfers. Minimize or **Na pozadí** hides SMART, the space analyzer, image/audio converters, media metadata tools, search, synchronization, and checksum tools into independent side-by-side tiles. Clicking a tile or Detail restores its window and size. Only explicitly backgrounded tools and transfers appear. Tool completion stays available until the tool is restored or closed; completed transfers disappear. Each tile shows its own state and blue progress indicator (indeterminate when no honest total is available). Tiles adapt their widths and scroll horizontally when needed, preserving one row and file-panel height.

SSH terminal opening first asks for an explicit username on every launch. The default is password authentication; the password is entered directly into OpenSSH and never passed in command arguments or saved by this dialog. Profile keys/agent can be selected explicitly. Empty usernames are rejected instead of inheriting the Windows account. Opening SSH from SFTP/SCP or an SSHFS mount uses the current remote folder, with quoted remote-shell arguments; host-key pinning remains mandatory. A missing remote folder leaves the failed `cd` visible instead of silently entering another location. Remote folder startup expects a POSIX shell.
Background activity tiles share all available dock width; a single copy spans the entire row. The converter footer reserves a separate column for Background, so its primary Start conversion button stays visible. The analyzer keeps its six main footer actions in one row, with export, snapshots, duplicate search and repeat scan under More options. Disabled buttons retain readable grey captions without enabling unavailable commands. Settings → Updates now checks publisher release sources and supports verified, versioned 7-Zip, FFmpeg/FFprobe and rclone packages, deferred activation and rollback. smartmontools without a published SHA-256 links to the publisher; application updates remain unconfigured until a GitHub release address is supplied. See UPDATES.md.







## Updates and current limitations

See [Updates](UPDATES.md) for official sources, hash checks, staged activation and rollback. Magick.NET / OpenMP updates with the application as a matched set. File Compass self-updating has no configured release URL yet. Some MP3 inputs report inaccurate estimated durations and can currently fail output-duration verification despite successful encoding; the original input is retained.
